## 📖 阅读约定

每个章节末尾都有一个 `✅ 本章速查表`，用最简短的方式总结本章关键 API 和概念。可以在通勤路上快速复习。

代码块标记：
- 🔴 **内核态**：在内核模块/驱动中跑的代码
- 🟢 **用户态**：在普通应用程序中跑的代码
- 📄 **脚本/配置**：Makefile、shell 命令、DTS 等

所有示例都在 Linux 6.x 内核上验证过，理论上兼容 5.x。
